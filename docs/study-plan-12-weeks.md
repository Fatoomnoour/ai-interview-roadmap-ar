# 📅 12-Week Study Plan

هذه نسخة مكثفة؛ اجعليها 24 أسبوعًا إذا كان لديكِ 8–10 ساعات أسبوعيًا.

| الأسبوع | التركيز | التسليم |
|---:|---|---|
| 1 | Python, Git, Linux, typing | CLI + tests |
| 2 | SQL, data structures, statistics | تحليل dataset |
| 3 | Regression, classification, metrics | baseline notebook |
| 4 | Trees, ensembles, leakage, imbalance | error analysis |
| 5 | PyTorch, training loops | نموذج صغير |
| 6 | Embeddings, transformers, transfer learning | semantic search |
| 7 | FastAPI, Docker, CI | ML API |
| 8 | Monitoring, versioning, batch/online | production checklist |
| 9 | REST, webhooks, retries, queues | automation workflow |
| 10 | Prompting, structured output, RAG | citation-first RAG |
| 11 | Tools, state, MCP, agent safety | bounded research agent |
| 12 | System design + mock interviews | portfolio demo day |

## Daily Loop

ابدئي بـ20 دقيقة مراجعة، ثم 60–90 دقيقة بناء، ثم 20 دقيقة كتابة ما تعلمته أو حل سؤال مقابلة. في نهاية كل أسبوع سجّلي demo قصيرًا أو أضيفي diagram إلى المشروع.

## Exit Criteria

لا يُعد الأسبوع منتهيًا بإنهاء الفيديوهات فقط. يجب وجود artifact قابل للمراجعة، مثل commit، اختبار، تجربة موثقة، رسم معماري، أو إجابة مكتوبة مع trade-offs.
