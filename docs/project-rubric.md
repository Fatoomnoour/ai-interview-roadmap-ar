# ✅ Project Rubric

| Dimension | 0 | 1 | 2 |
|---|---|---|---|
| Problem framing | unclear | defined | tied to user/business outcome |
| Technical depth | tutorial copy | working prototype | tested, measured, production-aware |
| Evaluation | none | one metric | golden set + error analysis + regression |
| Reliability | happy path | basic errors | retries, timeouts, rollback, observability |
| Safety | ignored | basic secrets hygiene | permissions, PII, injection/threat model |
| Communication | code only | short README | diagram, trade-offs, demo, interview story |
