# 📣 Marketing Playbook

الهدف ليس جمع Stars بأي طريقة، بل جذب أشخاص سيستخدمون الريبو، يفتحون Issues مفيدة، ويضيفون محتوى. **القيمة أولًا، ثم الطلب الواضح، ثم الاستمرارية.**

## Positioning

استخدمي جملة واحدة ثابتة:

> خريطة طريق عربية/إنجليزية عملية للتحضير لمقابلات ML وLLM وAgentic AI، تجمع بين المذاكرة، مشاريع الـPortfolio، وProduction thinking.

## قبل النشر

| الأصل | المطلوب |
|---|---|
| README | قيمة واضحة خلال أول شاشة، روابط مباشرة للـStudy Tracker والمشاريع |
| Demo | صورة أو GIF قصير يوضح شكل الخطة أو المشروع |
| Contribution | `CONTRIBUTING.md`، labels مثل `good first issue` و`help wanted` |
| Community | Issue templates لاقتراح مصدر، مشروع، أو تصحيح |
| Discoverability | description وtopics وكلمات ML/LLM/Agents/Automation |
| Proof | مثال حقيقي: أسبوع مذاكرة، مشروع منفذ، أو نتيجة تقييم |

## LinkedIn Strategy

انشري 2–3 مرات أسبوعيًا لمدة 4 أسابيع، مع اختلاف الزاوية. لا تنشري الرابط وحده؛ قدّمي درسًا صغيرًا يمكن الاستفادة منه حتى دون فتح GitHub.

| المنشور | الفكرة | CTA |
|---|---|---|
| Launch | لماذا بنيتِ الريبو وما المشكلة التي يحلها | "ما أصعب جزء في التحضير؟" |
| Learning post | اشرحي RAG evaluation أو الفرق بين workflow وagent | "أضفتِ إجابتك إلى النقاش؟" |
| Build log | شاركي تغييرًا محددًا ولقطة من tracker | "ما الذي ستضيفينه؟" |
| Community request | اطلبي مراجعة مصدر أو مشروع | "افتحي Issue بدل إرسال DM" |

## Reddit Strategy

اختاري المجتمع المناسب لكل نوع من المحتوى، اقرئي القواعد قبل النشر، وشاركي في نقاشات الآخرين قبل الترويج. في r/opensource مثلًا تظهر قواعد صريحة ضد spam وexcessive self-promotion وlink aggregation، لذلك يجب أن يكون المنشور on-topic ويقدم تفاصيل قابلة للنقاش.[^1]

| نوع المجتمع | زاوية مناسبة | تجنبي |
|---|---|---|
| Open source | اطلبِي review على structure أو contribution | "ادخلوا اعملوا Star" فقط |
| Machine Learning | شاركي جزءًا عن evaluation أو study method | ادعاء أن الأسئلة رسمية من شركة |
| LLM/Agents | ناقشي RAG/agent trade-off مع رابط كمرجع | عنوان clickbait أو claims مبالغ فيها |
| Programming/Career | شاركي template وتجربة بناء | تكرار نفس الرابط في مجتمعات كثيرة |

### Reddit post template

```text
Title: I built an Arabic/English roadmap for ML, LLM and Agentic AI interview prep — looking for critique

I kept finding resources that were either theory-only or scattered across many bookmarks, so I organized a practical roadmap from Python to production agents.

It includes a copyable study tracker, portfolio project rubric, free official resources, and original practice questions for LLM/Agentic AI system design. It is not a list of leaked interview questions.

Repository: https://github.com/Fatoomnoour/ai-interview-roadmap-ar

I would especially appreciate feedback on:
1. missing topics in the agent safety section;
2. whether the project progression is realistic;
3. useful free resources I should add.

I will respond to comments and update the roadmap based on useful feedback.
```

## 30-Day Launch Cadence

| الأيام | النشاط |
|---|---|
| 1–3 | أصلحي الروابط، أضيفي screenshot، جهزي 3 Issues سهلة |
| 4 | LinkedIn launch + سؤال مفتوح |
| 5–7 | ردي على التعليقات وأضيفي أول تحسين |
| 8–14 | منشور تعليمي عن RAG أو metrics، ثم Reddit في مجتمع مناسب |
| 15–21 | شاركي build log واطلبي مساهمات محددة |
| 22–30 | انشري changelog، اعرضي top contributors، واكتبي ما تغير بناءً على feedback |

## Growth Loops

1. **Resource loop:** كل مصدر جديد يضاف مع سبب اختياره ومستوى مناسب له.
2. **Project loop:** كل مشروع يولد issue صغيرة يمكن للمساهم تنفيذها.
3. **Learning loop:** كل أسبوع دراسة ينتج ملخصًا أو diagram أو test.
4. **Community loop:** كل مساهمة تُذكر في changelog ويُشكر صاحبها.
5. **Search loop:** استخدمي عناوين واضحة مثل `LLM Interview Prep` و`Agentic AI Roadmap` دون حشو كلمات مفتاحية.

## Metrics Worth Tracking

| Metric | ماذا يعني؟ |
|---|---|
| Unique visitors | هل يصل المحتوى لجمهور جديد؟ |
| Clone/readme clicks | هل يجد الزائر قيمة واضحة؟ |
| Returning visitors | هل يعود للاستخدام؟ |
| Issues/PRs | هل المجتمع يساهم؟ |
| Stars | إشارة اهتمام، وليست مقياس الجودة الوحيد |

## ما يجب تجنبه

لا تشتري Stars أو تستخدم engagement pods أو تنشر نفس الرابط آليًا في عشرات المجتمعات. لا تقدمي أسئلة على أنها "أسئلة Google أو OpenAI الحقيقية"، ولا تنسبي مصادر مجانية دون التحقق من الترخيص والإتاحة. الصدق والرد على feedback يبنيان نموًا أبطأ لكنه أكثر استدامة.
